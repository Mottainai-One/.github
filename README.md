# Configuração GitHub da organização

Este repositório reservado, chamado .github, é o ponto da organização Mottainai-One para arquivos de configuração compartilhados do GitHub.

## Conteúdo atual

Na branch padrão, o repositório contém este README e a licença MIT. Ainda não há templates de issues, templates de pull request ou workflows compartilhados versionados aqui.

Quando esses arquivos forem adicionados, os arquivos de comunidade podem fornecer padrões para repositórios da organização que não tenham uma versão própria. Workflows reutilizáveis precisam ser chamados explicitamente pelos projetos.

## Contribuição

Adicione somente configurações que façam sentido para vários repositórios. Antes de contar com um arquivo como padrão, confirme seu comportamento na documentação do GitHub e verifique se os projetos não possuem configuração local que o substitua.
